The shared context loads initial tasks from a JSON file through src. Change the source URL to load another JSON object containing tasks; local edits and restored browser data remain protected. Collections saves to local storage. Here, [sync] optionally sends only sync-keys to an HTTP endpoint.

Request configuration

Sending requires a server that accepts the selected method. The checkout's development server provides an optional in-memory API at /api/tasks. Static hosting needs only the JSON source and browser storage.
